# Dhamana product documents

## Value proposition

Dhamana is a crypto P2P marketplace with a built-in escrow intermediary. The platform protects transactions by locking seller assets in a 2-of-3 multisig vault and enabling dispute resolution by a trusted arbiter.

## Use cases

- crypto-for-crypto
- crypto-for-bank transfer
- crypto-for-digital service
- crypto-for-gift card and digital goods
- reverse auction for buyers
- group purchase deals

## Revenue model

- transaction fee: 0.5% to 1.5%
- professional seller subscriptions
- arbitration and verification fees
- fast-withdraw fees
- merchant API access

## Security model

- seller key
- buyer key
- platform key
- 2-of-3 signature requirement to release assets
- evidence review and arbitration window 24–48h
- ratings tied only to completed trades
